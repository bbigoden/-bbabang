# 페이지 폭 표준 (max-width)

부소장은 페이지별로 최대 폭(max-width)을 Tailwind `max-w-*` 클래스로 지정합니다.
현재 11종이 산발적으로 쓰이고 있어, 신규/리팩터링 시 아래 4가지 표준 중 하나를
우선 사용합니다.

> 이 문서는 가이드라인입니다. 코드 변경 없이 향후 작업 기준만 정의합니다.

## 표준 4종

| 등급 | Tailwind | 픽셀 | 용도 | 예시 페이지 |
|-----|----------|-----|------|-----------|
| 광폭 | `max-w-7xl` | 1280px | 대시보드 · 관리자 · 데이터 테이블 위주 | `/admin/*` 전체 |
| 일반 | `max-w-5xl` | 1024px | 일반 콘텐츠 · 리스트 · 상세 페이지 | `/brokers`, `/explore/requests`, `/regions/*`, `/property/[id]`, `/broker/[id]` |
| 텍스트 | `max-w-2xl` | 672px | 약관 · 정책 · 도움말 · 좁은 폼 | `/terms`, `/privacy`, `/support` |
| 폼 | `max-w-md` | 448px | 인증 · 단일 입력 · 모달 본문 | `/auth/login`, `/auth/signup`, `/auth/reset-password`, `/account-suspended` |

## 사용 규칙

1. 신규 페이지는 반드시 4종 중 하나에서 출발한다.
2. 4종으로 안 맞는 경우(폼이지만 약간 넓다 등) 가장 가까운 표준을 쓰고,
   콘텐츠 폭을 좁히는 식으로 맞춘다.
3. 기존 페이지를 리팩터링할 때 가능하면 4종으로 수렴시킨다.
4. 콘텐츠 페이지 내부의 카드/모달은 페이지 max-w와 별개로 자유롭게 정한다.

## 현재 사용 분포 (2026-06 기준)

| Tailwind | 횟수 | 비고 |
|---------|-----|------|
| `max-w-7xl` | 19 | **표준 (광폭)** — 전 admin 페이지 |
| `max-w-md` | 20 | **표준 (폼)** — auth + 일부 컴포넌트 |
| `max-w-5xl` | 17 | **표준 (일반)** — 일부 콘텐츠 페이지 |
| `max-w-sm` | 17 | 비표준 — 폼·다이얼로그 일부 |
| `max-w-2xl` | 12 | **표준 (텍스트)** — terms/privacy 등 |
| `max-w-xl` | 10 | 비표준 — 좁은 폼 일부 |
| `max-w-3xl` | 9 | 비표준 — `/broker/[id]`, `/property/[id]` 상세 |
| `max-w-4xl` | 8 | 비표준 — 결제·정산 위주 |
| `max-w-full` | 6 | 비표준 — 채팅·풀너비 컨테이너 |
| `max-w-lg` | 6 | 비표준 |
| `max-w-xs` | 3 | 비표준 — 매우 좁은 카드 |
| `max-w-6xl` | 2 | 비표준 |

## 비표준 → 권장 매핑 (점진 마이그레이션 가이드)

- `max-w-xs / sm` 좁은 폼 → `max-w-md` 로 통일
- `max-w-lg / xl` 중간 폼 → `max-w-md` (폼) 또는 `max-w-2xl` (텍스트)
- `max-w-3xl` 상세 페이지 → `max-w-5xl` 로 확장 (broker/[id], property/[id])
- `max-w-4xl` → 콘텐츠 성격에 따라 `max-w-5xl` (리스트형) 또는 `max-w-2xl` (텍스트형)
- `max-w-6xl` → `max-w-5xl` 또는 `max-w-7xl` 둘 중 하나로 흡수
- `max-w-full` → 채팅·풀너비 UI 외에는 `max-w-7xl` 로 좁히기 검토

## 표준 외 허용 케이스

- **채팅 페이지** (`/chat/[proposalId]`): `max-w-full` 또는 페이지 내 분할 레이아웃이라
  표준 폭 적용이 어려움. 별도로 둠.
- **모달/다이얼로그**: 페이지가 아니라 컴포넌트 단위. `max-w-md / lg / xl` 등 자유.
- **외부 임베드·iframe·다국어 안내**: 콘텐츠 폭에 맞춰 자유.
